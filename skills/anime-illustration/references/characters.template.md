# Confirmed character profiles

Use this file as the agent's long-term memory of characters you have confirmed together. Copy `characters.template.md` to `characters.md` and fill one section per character; `characters.md` is gitignored, so personal and OC profiles stay local.

Every entry should be confirmed against a reference the user approved — not guessed from memory. When the user's latest correction disagrees with an older note, the correction wins.
